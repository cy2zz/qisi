# B05｜合法异解与动态路线纵向切片

Task ID：B05（`in_progress`；AT16 的真实模型异解链和安全路线归属 UI 已验证，七类策略全矩阵与真实 MySQL 路线持久化仍未完成）。

需求 / 验收：FR07；本切片只覆盖 AT16 `passed_self_review`。

Specify：竞赛题和高考压轴题允许多条合法路线。学生用 AM–GM 正确求得最小值时，系统不能因教师包只列了导数路线而判错，也不能把“最小值已完成”冒充“单调性也已完成”。诊断应记住局部有效产物，触发 route_review；Preparation 应建立 `source=student` 的有效子路线；Strategy 应沿学生成果继续，只补仍缺的单调性目标。

失败先行：第一版真实模型 oracle 粗暴要求整份 Diagnosis 和 RoutePatch 的顶层 `judgment/math_status` 都为 `valid`。真实输出明确认可 AM–GM 路线正确、满足 minimum，同时因题目还要求单调性而把完整作答标为 incomplete/invalid，导致评估失败。该失败证明“局部数学有效”与“完整任务完成”必须分开。本轮改为检查局部 satisfied decision、有效 student subroute、route_review、作者来源和剩余 goal，不降低数学要求。

实现：新增 `server/scripts/evaluate-alternative-route-live.ts`，直接运行真实 DiagnosisAgent → PreparationAgent(route_review) → StrategyAgent，不依赖当前缺 workflow 表的业务数据库。评估固定提供教师导数路线和学生 AM–GM 异解，严格断言最小值局部完成、学生来源保留、学生 subroute 数学状态为 valid、单调性 gap 单独留下、后续策略不重判 AM–GM 为错误。每次模型调用使用独立 timeout signal，避免多节点共享一个绝对超时导致后续节点被误取消。应用侧 `routePatchIsUsable` 改为按路线粒度保留已由 Guard 接受、verification pass、`source=student` 且 `math_status=valid` 的局部异解；顶层 patch 因整题未完成而标 invalid 时不再把局部正确成果一起丢弃。unknown、有 blocking issue、Guard 未接受或子路线本身 invalid 仍然拒绝。审核通过的 patch 作为私有 `route_patch_approved` 事件与消息、版本和幂等响应在同一事务提交；下一轮按会话 task id 恢复并合并进 Diagnosis 的 decisions/routes 和 Strategy 的 route_patch，跨会话或结构失效的 patch 不采用。公开响应只附带安全归属枚举：学生有效子路线为 `student`，否则为 `coauthored`；SSE、幂等响应和会话消息均不下发私有 patch。该枚举随 SSE done、请求幂等回放、guide message metadata 与 `guide_message_committed` 事件持久化。学生端显示“沿你的路线”或“共同补全”，刷新恢复后保留，同时把焦点还给输入框。

验证：`npm --prefix server run eval:alternative-route-live` 退出 0；真实模型 `gpt-5.5-2026-04-24`，Diagnosis/Preparation/Strategy usage 均 reported。最终 Diagnosis `locallySatisfied=[minimum]`、focus=`monotonicity`、routeReviewNeeded=true；Preparation 生成 `source=student, math_status=valid` 的 AM–GM 子路线和共同完成路线；Strategy 选择 `advance`、L1，只继续单调性目标。新增应用门禁失败测试先证明旧实现会向 Strategy 传 `route_patch=null`，修复后保留原有未核对 patch 拒绝用例。服务端定向测试覆盖私有事件提交、同会话恢复、跨会话拒绝、下一轮注入、SSE 不泄露和幂等重放；前端恢复 1 file / 11 tests 通过。路线归属在 1440×900、1280×800、390×844、360×800 四个视口共 4 个 Playwright 用例通过，覆盖实时 SSE、刷新恢复和焦点返回。前后端全量 unit、typecheck、lint、build 均通过。

限制：当前只是一道 AM–GM 异解的 model_review；没有覆盖坐标/向量、构造函数、分类讨论等竞赛常见异解。route patch 的事务提交与恢复使用数据库门面 fixture、UI 刷新使用 fixture session，尚未在真实 MySQL 完整 API 中验证崩溃恢复。`real_student_observation: not_run`。
