# B02｜经核对的备课包与哈希缓存

Task ID：B02（`in_progress`）。

本轮目标：将 PreparationAgent 的结构化候选收口为可核对的 Packet，而不是把模型返回的 `ready` / `verified` 当成事实；缓存键绑定 `problem_hash + prompt/model/config`，题干变化必须失效；未通过数学来源、语义图与 Guard 检查的结果保留为 `needs_review`，不得成为教学依据或独立检验任务。

假设与边界：`Problem` 来自服务端题库快照；只有服务端已标记 `ready` 且确有参考材料时，代码才生成一条可信 `source_reference` 记录。模型输出中的 `human_reviewed`、`source_reference`、`deterministic_check` 一律不自动采信；模型生成的迁移题默认 `verified=false`，等待后续真实人工或确定性复核。B 负责 Preparation/Policy，A 的 MySQL 表与数据库类型按单 AI 串行检查点单独记录，不建立第二套连接池。

失败先行：覆盖错误 problem hash、仅 `model_checked`、Guard `unknown`、路线依赖成环、少于两项检验候选以及旧 hash 缓存误命中。失败必须来自当前实现把候选误当成就绪，而不是依赖缺失。

验收映射：AT05、AT06、AT07。完整真实模型数学审题与人工抽检不由自动测试冒充；`real_student_observation: not_run`。

实现结果：新增 `packets` MySQL 缓存与 PreparationService；缓存键绑定 problem hash、prompt/model/config/reference。候选先经 Zod、跨字段语义校验和独立 Guard；模型伪造的非模型核对类型被降级，迁移检验题统一保持未核对。真实 MySQL 8.0.45 已验证 `needs_review -> ready` 精确键往返，正式 8.4 与真实题库人工审题仍未完成。

## 2026-09-19｜原卷解析图片与学习会话接线

真实题库只有题目图和原卷解析图，之前 PreparationService 虽能生成 Packet，却没有接入图片，也没有进入学生实际选择题目的主链。本次将解析图作为私有多模态输入同时传给 Preparation 与 Packet Guard；缓存版本新增图片 MIME 与字节摘要，图片变化不会误用旧 Packet。学生选择题库题后，服务端读取受信 OSS 解析图、并行生成公开题面分析与私有 Packet，将精确 Packet 版本写入不可变 `preparation_bound` 会话事件。教学轮只加载题目哈希与事件版本都匹配且状态为 `ready` 的 Packet；`needs_review` 版本只保留审计，绝不进入 Diagnosis/Strategy。

学生页只显示安全状态“原卷解析已核对 / 题解依据仍在核对 / 原卷解析暂时不可用”，不返回 Packet、解析图、参考答案或未来检验题。准备失败不换题、不丢题，也不把未经检查的答案用于教学。真实 MySQL 验证了 Packet 版本和安全状态随会话恢复；真实 provider 多模态尝试返回 HTTP 502，因此本轮只证明安全降级与接线，不声称真实题库 Packet 已 ready，AT07 继续为 partial。

## 2026-09-19｜ready Packet 迁移题进入独立检验

AssessmentRepository 现在从当前 owner/session 的最新有效 `preparation_bound` 事件恢复 Packet，只接受事件与表记录在 `problem_hash + packet_version + ready` 上精确匹配、Packet Schema 合法且题库题 ID 一致的版本。Packet 的迁移题仍保持 `verified=false`；Assessment 不采信 Preparation 的模型核对标记，而是使用自己的 Guard 对候选、原题、分析、路线和参考答案重新审查。只有 Guard `accept` 才创建检验 attempt；已见题或同 equivalence group 会跳过，剩余在线生成与 Packet 候选共享原有候选预算。

fixture 单测证明命中 Packet 时只发生独立 Guard 调用、不调用新的任务生成器；真实 MySQL 8.0.45 输出 `preparedCheckTaskBound=true`，证明精确绑定恢复。该证据不等于人工数学审题，也没有真实 provider 延迟对照；AT07 仍为 partial，`real_student_observation: not_run`。
