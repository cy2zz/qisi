# A03｜题目图片识别与输入组件纵向切片

Task ID：A03（`implemented_waiting_review`；图片题识别、手写逐行确认、私有媒体、教学/检验 provenance 与 TTL 清理均已实现，待独立复核）

需求 FR / 验收 AT：FR04、FR05、FR16；AT09 `partial`（真实手写识别质量尚未验证），AT10、AT11 `passed_self_review`；不得把 fixture 转写冒充真实模型识别质量或独立复核。

输入/输出与契约：输入为登录学生提交的一张 JPEG/PNG/WebP，或题库中通过 `questionId` 回查得到的永久 OSS 题图；输出为题型、忠实题干 Markdown/LaTeX、图片中明确出现的答案/解答和不确定项。手写作答先生成 owner-scoped transcript revision；所有 uncertain 行被更正或明确确认后才生成新的 confirmed revision，且只有文本与该 revision 完全一致时才能进入教学或独立检验。题库图片识别后的题干进入当前题目的分析和后续问答上下文。

不变量：只接受 ≤8MB、≤2000 万像素且能被 sharp 完整解码的单页 JPEG/PNG/WebP；MIME 必须与解码格式一致；SVG、伪图片、多页图片和跨 Origin 请求拒绝。视觉提示明确“不要解题”，不得补造缺失条件、答案或纠正学生数学。浏览器不接收模型密钥；题库图片只能按题目 ID 从数据库读取，并且服务端只允许 `https://qisi-main.oss-cn-hangzhou.aliyuncs.com/历年试题/` 下无查询参数、无重定向的永久 URL，防止任意 SSRF。学生图片使用服务端生成的私有文件名保存，通过登录态 owner-scoped 接口读取；24 小时后删除原图字节，未确认 transcript 同步删除，已确认文本证据保留但与媒体解绑。

允许写集 / 排除写集：本轮写 `server/db/{media,transcripts}.sql`、`server/src/features/media/**`、题库读取与分析接线、教学/Assessment provenance、`web/src/features/input/**`、学习页与独立检验输入接线及相关测试；不实现公开图片代理，不把未确认识别标为学生 submission，不改 `tasks.json` 状态。

前置依赖：A01/B01 整卡仍未完成；现有登录、ModelPort、题库三表和学习页可用。本切片在这些已运行接口上纵向实现，不据此宣称满足完整工作流恢复门禁。
