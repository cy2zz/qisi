# A03｜题目图片识别与输入组件纵向切片

Task ID：A03（`in_progress`；图片题识别与输入接线 implemented，确认 revision、私有媒体持久化和 TTL 删除未完成）

需求 FR / 验收 AT：FR04、FR05、FR16；AT09、AT10、AT11 均为 `partial/not_run`，不得把当前题目图片识别冒充完整手写确认链路。

输入/输出与契约：输入为登录学生提交的一张 JPEG/PNG/WebP，或题库中通过 `questionId` 回查得到的永久 OSS 题图；输出为题型、忠实题干 Markdown/LaTeX、图片中明确出现的答案/解答和不确定项。学生上传的不确定识别只回填编辑器等待确认；题库图片识别后的题干进入当前题目的分析和后续问答上下文。

不变量：只接受 ≤8MB、≤2000 万像素且能被 sharp 完整解码的单页 JPEG/PNG/WebP；MIME 必须与解码格式一致；SVG、伪图片、多页图片和跨 Origin 请求拒绝。视觉提示明确“不要解题”，不得补造缺失条件、答案或纠正学生数学。浏览器不接收模型密钥；题库图片只能按题目 ID 从数据库读取，并且服务端只允许 `https://qisi-main.oss-cn-hangzhou.aliyuncs.com/历年试题/` 下无查询参数、无重定向的永久 URL，防止任意 SSRF。图片原始字节只用于当前识别，不在本切片持久化。

允许写集 / 排除写集：本轮写 `server/src/features/media/**`、题库读取与分析接线、`web/src/features/input/**`、学习页输入接线和相关测试；不新增/修改媒体 DDL，不实现未授权的公开图片代理，不把识别内容标为学生已确认 submission，不改 `tasks.json` 状态。

前置依赖：A01/B01 整卡仍未完成；现有登录、ModelPort、题库三表和学习页可用。本切片在这些已运行接口上纵向实现，不据此宣称满足完整工作流恢复门禁。

失败测试计划：上传/粘贴图片后必须显式触发识别；真实解码和尺寸限制必须覆盖；视觉模型只提取可见内容；不确定识别回填编辑器而非自动教学；题库选图必须提交 `questionId`，后端从数据库回查并安全读取 OSS 图片，识别后的题干必须成为后续对话上下文；任意外部主机和超限响应必须在模型前拒绝。

实际失败证据：图片输入组件、客户端和媒体接口测试最初分别因实现不存在而失败；题库多模态接线前，真实浏览器选择 2025 上海卷第 1 题后模型只看到 Markdown 图片链接，返回“当前无法读取图片中的具体数学内容”。新增失败测试后，前端定向测试退出 1（请求体缺少 `questionId`），服务端定向测试退出 1（`QuestionImageLoader` 不存在，分析控制器没有题库/视觉依赖）。

实现与迁移：新增图片粘贴/选择、单图预览、大小显示、移除/重试、识别状态和“不确定则确认”的输入体验；NestJS 媒体接口执行 Origin、登录、真实解码、格式/像素/字节限制，再经 ModelPort 发送 data URL 给真实视觉 provider。题库选择额外提交 `questionId`；分析控制器从数据库读取题干或题图，题图经固定 OSS 域名/目录/无重定向/流式 8MB 上限校验和 sharp 解码后先忠实转写，再进行结构分析；返回的 `problemMd` 写入当前 React 题目状态，后续问答不再把图片 URL 当题干。不确定项在分析区以琥珀提示显示。

实际验证：图片媒体/ModelPort 定向测试 4 files / 7 tests 通过；题库视觉接线定向 server 2 files / 8 tests、web App 7/7 tests 通过。完整 web 13 files / 39 tests、typecheck、lint、build 均退出 0；server typecheck、lint、build 均退出 0。server 完整测试 233 passed / 12 failed，12 项均为既有 prompts CRLF/LF 逐字节差异，与本切片无关。内置浏览器使用真实登录、真实 MySQL、真实 OSS 和真实视觉模型选择 2025 上海卷第 1 题，正确识别 `$U=[2,5]$` 与 `$A=[2,4)$`、生成补集分析，并在“提示一点”后继续基于识别题干回应。`git diff --check` 退出 0。
