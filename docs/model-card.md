# 启思模型与教学能力卡（开发快照）

**基线 qisi-3.1；日期 2026-09-20；发布状态 not_ready。** 本文描述仓库设计、当前改动与证据限制，不是模型厂商评测或学生学习成效证明。

## 用途与角色

高三数学辅助教学：Preparation 准备可核对题包；Diagnosis 引用当前 confirmed revision 诊断；Strategy 选择下一步干预；Assessment 在新任务上评估（实现归 A）；Renderer 仅生成批准内容，Guard 核对候选。角色不是开发子 Agent，亦不意味着六个模型各自独立训练。

项目基线与提示版本独立：现有提示标记 `prompt-v3.0`，不代表产品退回 qisi-3.0。本次未改提示文本。实际文件与 SHA256 见 `artifacts/release/teaching/B-20260920-local/snapshot.json`。本轮 provider 为 fixture/合成假对象，**没有选定或调用真实模型**；历史交接提及的模型不作为此次结果证据。

## 可验证的本轮改动

- 新严格入口核对 task、最新 confirmed revision、引文、假设/探针、unknown 与结论、批准披露和用户意图。
- canonical goal 注册处理父链与冲突；第三个探针不再靠删除结构字段后继续放行。
- 台阶候选只使用独立当前证据；异解需结构/依据/Guard 与无冲突核验，不因不同参考路线自动判错。
- 纠错保留历史与帮助记录，使依赖旧输入的嵌套及后继结论失效。
- 教师独立鉴权、显式 POST 确认、先持久曝光再安全投影的端口和模块/UI；测试使用 fake store，真实授权事务未完成。
- 单次预算授权/结算防重复；排队计时、超时取消、迟到输出失效、异常信息不嵌入原始 provider 内容。客户端取消不保证远端供应商停止计费。
- 离线评估工具保留失败/缺失/unknown/人工分歧/不可比条件，不预填优势。

以上有未接线候选组件，不能概括为整个应用已具备全部能力。精确测试结果见 `artifacts/acceptance/B-20260920-local/run-summary.json`，历史通过不覆盖当前失败。

## 风险及数据边界

错误归因、过提示、错误接受/拒绝异解、OCR歧义、提示注入、泄露未来题/答案、虚假独立通过和状态恢复竞态必须保留负例。默认不流式发送未校验内容；私有题解/提示/凭据不发客户端。教师摘要不是隐藏思维链。新代码不处理真实学生数据；今后评估需授权、脱敏、最小化保留与删除流程。
